Auuki Side Repo with AI Videos

A fork of Auuki with AI-generated route videos — setup guide for Mac, Linux and Windows

First-time setup

1
Download the launcher

Click the button below to download setup.sh, then save it somewhere easy to find (e.g. your Desktop).

2
Open Terminal

Press ⌘ Space, type Terminal, press Enter.

3
Run the launcher

Type the following, then press Enter. Auuki will download automatically (it's large — give it a minute).

bash ~/Desktop/setup.sh

Replace ~/Desktop/setup.sh with wherever you saved the file.

4
Use Chrome or Edge

The browser opens automatically at http://localhost:3000. Bluetooth connectivity requires Chrome or Edge — Safari will not work.

Every time after that

Just run the same command again — if the app is already downloaded it starts immediately:

bash ~/Desktop/setup.sh

Updating to the latest version

Delete the auuki_with_video-main folder (created next to setup.sh), then run the launcher again. It will re-download the latest.

First-time setup

1
Download both launcher files

Save these two files in the same folder (e.g. your Desktop):

2
Double-click setup.bat

If Windows asks "Do you want to allow this app to make changes?" — click Yes. If it shows a blue SmartScreen warning, click More info → Run anyway.

3
Wait for the download

Auuki downloads automatically (the video files are large — give it a few minutes on first run). A browser window opens when it's ready.

4
Use Chrome or Edge

The app opens in your default browser at http://localhost:3000. Bluetooth requires Chrome or Edge.

Note: A black terminal window stays open while Auuki is running — that's normal. Closing it stops the app.

Every time after that

Double-click setup.bat again. If the app is already downloaded it starts in a few seconds.

Updating to the latest version

Delete the auuki_with_video-main folder (in the same folder as setup.bat), then double-click setup.bat again.
